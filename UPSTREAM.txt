Local modifications (outside vendor/):
- src/wasm.rs          — Emmu WASM facade: RGBA8888 stacked frame, f32 stereo
                         audio queue, button/touch input, EMMUNDS1 save states,
                         cartridge save RAM import/export and reset.
- src/renderer_3d.rs   — synchronous in-thread 3D scanline renderer, replacing
                         the upstream Web Worker + atomics + shared-memory path
                         so the core works without COOP/COEP headers.
- js/adapter.js        — worker protocol adapter (object output with frame and
                         audio metadata), copied to the UI at build time.
- rust-toolchain.toml  — pins nightly-2025-12-15, the toolchain compatible with
                         the `proc-bitfield` nightly feature used upstream.

No copyrightable Nintendo BIOS or firmware is bundled: dust uses an HLE BIOS
and generates the default firmware at runtime.
